# Security Policy

## Reporting a vulnerability

Please do not report security issues in public issues, discussions, or pull requests.

Report them privately through GitHub's [private vulnerability reporting](https://github.com/thorrsson/osx-unifi/security/advisories/new) instead. Include steps to reproduce, the affected version, and the impact you expect.

You should receive a response within a week. Once a fix is released, the advisory will be published with credit to the reporter unless you ask otherwise.

## Supported versions

Only the latest release receives security fixes. The app updates itself through Sparkle, so staying current is the best protection.
